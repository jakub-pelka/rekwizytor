Logo Rekwizytora: kurtyna idzie w górę. Zasady są w księdze znaku i w sekcji Logo opisu marki.

- `rekwizytor-znak.svg`: znak, kafelek `kurtyna` z otworem `scena`. Zwinięty sidebar, nagłówek mobilny, ekrany błędów.
- `rekwizytor-znak-mono-kurtyna / -czarny / -bialy.svg`: jednokolorowy, otwór wycięty.
- `rekwizytor-logo-light.svg` / `-dark.svg`: logo poziome. Sidebar, nagłówki, stopki.
- `rekwizytor-logo-tagline-light / -dark.svg`: poziome z hasłem. Dokumenty, PDF.
- `rekwizytor-logo-pion-light / -dark.svg`: pionowe z hasłem. Logowanie, okładki, ekran startowy.
- `rekwizytor-logo-mono-czarny / -bialy.svg`: logo jednokolorowe.
- `favicon.svg`: favicon (16 i 32 px).
- `logo-icon.png`: znak 512 px z przezroczystymi rogami (PWA „any”).
- `app-icon-ios.png`: iOS i macOS, 1024 px, pełny kwadrat bez przezroczystości.
- `app-icon-android-512.png`: Google Play, zbliżenie 2b.
- `android-background / -foreground / -monochrome.png`: ikona adaptacyjna Androida, płótno 108 dp (432 px).
- `icon-maskable-512.png`, `icon-monochrome-512.png`: PWA maskable i monochrome, zbliżenie 2b.
