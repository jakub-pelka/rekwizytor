Etykieta statusu lub metadanej — kropka w kolorze statusu plus słowo.

Status nigdy nie jest przekazywany samym kolorem: kropka i słowo zawsze idą razem.

- `success` — na miejscu, sprawdzone, gotowe.
- `warning` — wypożyczony, do naprawy, niekompletny.
- `danger` — zaginiony, zniszczony. Tylko stany wymagające reakcji.
- `info` — w spektaklu, zaplanowany.
- `brand` — wyniki i sugestie AI (zastępuje dotychczasowe fioletowe i niebieskie akcenty AI).
- bez wariantu — stany neutralne (archiwum). `--plain` bez kropki — metadane: lokalizacja, oznaczenia („Premiera”). Same liczby to nie badge, tylko licznik (karta „Licznik”).

Numer inwentarzowy to nie badge: użyj `.rk-id` (styl `inventory-id`, Courier Prime).
