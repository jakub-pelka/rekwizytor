Rozwijane menu akcji pod przyciskiem „…” przy rekwizycie, spektaklu, scenie.

- Wyzwalacz: przycisk z ikoną `more` i `aria-label` z nazwą rzeczy („Akcje: Kielich srebrny”).
- Panel `surface`, `radius-md`, `shadow-overlay`; pozycja 36 px z ikoną 16 px i opcjonalnym skrótem maszynopisem.
- Kolejność: najczęstsze na górze, separator, akcja niszcząca na końcu w `danger`. Wielokropek („Usuń…”, „Przenieś do sceny…”) gdy akcja otwiera okno.
- Strzałki przesuwają fokus, Enter wybiera, Esc zamyka i wraca fokusem na przycisk.
