Ikony kategorii rekwizytów (39) w gramatyce Lucide. Dwie osie: **typ przedmiotu → ikona**, **motyw spektaklu → tag**. Ikona mówi, czym jest przedmiot (butelka, kielich, szpada), a tag, do jakiego świata należy (wampiry, zakon, kabaret).

- Rodziny z wariantami (np. butelki: piwo, wino, whisky, szampan, wódka, plastikowa, apteczna) mają wspólny szkielet i różnią się jednym, dwoma szczegółami, żeby w 16 px dało się je odróżnić.
- Grupy pochodzą z burzy mózgów dla repertuaru Teatru Rozrywki. Nowe kategorie dorysowujemy według tych samych zasad: sylwetka czytelna w 16 px, najwyżej 6 ścieżek, bez wypełnień.
- Ścieżki SVG: `icons/rekwizytor-icons.json` (klucz `props`).
