Karta rekwizytu na tablicy scen (przypisywanie rekwizytów do scen przeciąganiem).

- Kolumna: `surface` z nagłówkiem maszynopisem (akt i scena) i licznikiem.
- Karta: `surface-raised`, uchwyt (ikona grip) po lewej, nazwa, numer `inventory-id`, opcjonalnie jeden badge.
- **Przeciągana karta** dostaje pieczątkę (`shadow-stamp-ink-lift`), ramkę `ink` i lekki obrót −1,5°: jedyne miejsce poza przyciskami, gdzie pojawia się twardy cień.
- Miejsce upuszczenia: przerywana ramka na `kurtyna-tint`.
- Na dotyk: przytrzymanie 300 ms rozpoczyna przeciąganie; zawsze jest też alternatywa bez przeciągania (menu „Przenieś do sceny…”).
