Ustawienia to jedna kolumna sekcji, a w sekcji wiersze `.rk-setting`: po lewej nazwa i krótkie wyjaśnienie, po prawej kontrolka. Bez kart i bez kolorowych ikon przy sekcjach.

- Sekcje: Konto · Wygląd i działanie · Listy rekwizytów · Teatr (tylko administrator, znacznik `administrator`) · O aplikacji.
- Nagłówek sekcji: nagłówek z linią (jak w całej aplikacji), zdaniem, bez wersalików.
- Kontrolki: `.rk-select` dla wyboru z listy, `.rk-switch` dla włącz/wyłącz, `.rk-tabs` jako przełącznik 2–3 opcji, przyciski `--secondary --sm` dla akcji, `.pl-link` dla przejść.
- Na komputerze po lewej spis sekcji (`.rk-settings-nav`), przyklejony przy przewijaniu.
- Na telefonie szerokie kontrolki schodzą pod opis (`.rk-setting--stack`).
- Każdy opis mówi, po co jest ustawienie, językiem pracowni („Ciemny lepiej sprawdza się w kulisach”), nie technicznie.
- Wylogowanie na końcu strony jako zwykły przycisk drugorzędny.
