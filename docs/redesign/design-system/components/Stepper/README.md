Kroki kreatora (import scen ze scenariusza, dodawanie spektaklu).

- Krok zrobiony: kółko `kurtyna` z ptaszkiem; bieżący: obrys `kurtyna-text` z poświatą `kurtyna-tint`; przyszły: obrys `border-strong`. Numery maszynopisem.
- Pod etykietą krótki stan („12 rozpoznanych”), gdy coś wiadomo.
- 3–5 kroków. Na telefonie kroki układają się pionowo, a linie znikają.
- Zrobione kroki są klikalne (powrót), przyszłe nie.
