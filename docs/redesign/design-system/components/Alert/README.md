Komunikat w treści strony — ikona w kolorze statusu, tekst `ink` na tle `*-tint`.

- Warianty: `info`, `success`, `warning`, `danger`, `ai` (wyniki rozpoznawania ze zdjęć, sugestie).
- Pogrubione zdanie mówi, co się stało; drugie — co zrobić.
- Bez emoji; ikona lucide 20px.

Konsument dostarcza: wariant, tytuł (opcjonalny), treść.
