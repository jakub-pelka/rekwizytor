Stan, gdy w miejscu treści nic nie ma: pusta scena, brak wyników, nowe konto.

- **Pełny** (pierwsze użycie, pusta scena): ilustracja zasłoniętej kurtyny z kształtów marki, tytuł mówiący co jest puste, jedno zdanie co zrobić, akcja główna i opcjonalnie druga jako ghost.
- **Kompaktowy** (brak wyników wyszukiwania): bez ilustracji, w jednym wierszu; podpowiada przyczynę (aktywne filtry) i daje „Wyczyść filtry”.
- Tytuł bez „Brak danych”; piszemy językiem teatru i w drugiej osobie.
- Ilustracja tylko z tokenów kurtyny, nigdy postacie ani emoji.
- **Kurtyna w górze** (wszystko zrobione, np. lista zadań 42/42): kotary zebrane po bokach, widać scenę. To jedyny pusty stan, który jest dobrą wiadomością, więc nie ma w nim akcji głównej, najwyżej link „Pokaż gotowe”.
- **Na telefonie** pusty stan stoi bez karty, prosto w treści ekranu, a akcja główna ma pełną szerokość.
- **Pulpit bez spektaklu dziś** to nie pusty stan: główna karta pokazuje najbliższy spektakl z odliczaniem w dniach i nadtytułem „Dziś nie gracie”.
- Przykłady wszystkich pustych stanów i błędów: płótno „Ekrany Rekwizytora”, sekcja „Stany”.
