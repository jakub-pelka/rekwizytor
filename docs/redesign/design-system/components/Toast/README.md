Krótkie powiadomienie o skutku akcji, w prawym dolnym rogu (na telefonie u dołu, na całą szerokość).

- Tło `surface-raised`, `shadow-overlay`; kolor niesie tylko ikona statusu, tekst zawsze `ink`.
- Jedno zdanie o tym, co się stało. Opcjonalnie jedna akcja tekstowa w `kurtyna-text`: „Cofnij”, „Ponów”, „Sprawdź”.
- Znika po 4 s (sukces, informacja). Błąd zostaje, dopóki użytkownik go nie zamknie albo nie ponowi.
- Wejście: wjazd od dołu 250 ms; w Próbie czytanej przenikanie. Maks. 3 naraz, najnowszy na dole.
