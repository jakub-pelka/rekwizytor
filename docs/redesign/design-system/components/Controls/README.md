Kontrolki wyboru: checkbox (kilka z wielu), radio (jedna z kilku), przełącznik (włącz/wyłącz natychmiast).

- Pole 20 px, zaznaczone: `kurtyna` z ramką `kurtyna-night`, znak `on-kurtyna`. Niezaznaczone: ramka `border-strong` (3:1).
- Checkbox ma stan pośredni (kreska) dla „Zaznacz wszystkie”, gdy zaznaczona jest część.
- Radio z opisem pod etykietą (`small`), gdy opcje wymagają wyjaśnienia (poziom animacji).
- Przełącznik tylko dla ustawień działających od razu, bez przycisku „Zapisz”.
- Cała etykieta jest klikalna; fokus jak we wszystkich kontrolkach. Wyłączone: 50% krycia.
