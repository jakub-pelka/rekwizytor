Dwa poziomy ruchu: **Premiera** (pełny) i **Próba czytana** (oszczędny), sterowane atrybutem `data-motion` na `<html>`. Kliknij „Odtwórz”, żeby porównać.

Wzorce ruchu marki: Kurtyna (wejście panelu), Trzy dzwonki (ładowanie), Bilety (postęp), Odhaczenie (lista zadań), Pieczątka (przycisk). Zasady i progi wykrywania sprzętu: sekcja „Ruch”.
