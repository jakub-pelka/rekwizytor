Kontener treści na `surface` z ramką `border`, `radius-md` i opcjonalnym nagłówkiem.

Zastępuje mieszankę `bg-gray-900` / `bg-neutral-900` — od teraz jedna powierzchnia `surface`.

- Nagłówek: `title` lub `heading` + opcjonalnie badge albo akcja po prawej.
- Padding `space-6` na desktopie, `space-4` na mobile.
- Bez kolorowych lewych krawędzi i gradientów; wyróżnienie przez badge lub `kurtyna-tint` w całości.

Konsument dostarcza: tytuł, treść, opcjonalnie akcje.
